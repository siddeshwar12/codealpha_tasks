# To-Do List

A lightweight, browser-based task manager built with vanilla HTML, CSS, and JavaScript.

## Features

- Add tasks with the button or the Enter key
- Delete tasks individually
- No build step or external dependencies

## Run locally

Open `index.html` in a modern browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Test

1. Enter a task.
2. Select **Add** (or press Enter).
3. Confirm the task appears, then select **Delete**.

## Deployment

This is a static site and can be deployed with GitHub Pages, Netlify, or Vercel without a build step.
